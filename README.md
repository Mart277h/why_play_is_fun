# Exploring Expectations in Play - Investigating a Predictive Processing Account of Enjoyment in Play
This repository contains all code related to the Master's thesis: __Exploring Expectations in Play - Investigating a Predictive Processing Account of Enjoyment in Play__

The purpose of this thesis is to investigate why play is fun and how expectations influence enjoyment in play. 

## Usage
Data from the thesis is not available, though all code for the preprocessing and analysis are available. 

Code for Experimental Design Evaluation analysis is found in Smiley_scale_analysis.Rmd

Code for Enjoyment Rating Analysis is found in Rating_analysis.Rmd

Code for Preference Choice Analysis is found in Choice_analysis.Rmd

Preprocessing was done in data_preprocessing.Rmd
